# Web Technologies 2 – Backend Assignment

## Description
Simple Express API with CRUD operations using JSON file storage.

## Install
npm install

## Run
npm start

## API Routes
GET /  
GET /hello  
GET /time  
GET /status

GET /tasks  
POST /tasks  
PUT /tasks/:id  
DELETE /tasks/:id

## Example POST, PUT Request Body
{
"name": "Buy milk"
}
